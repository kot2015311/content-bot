# Контент-бот

[English version](README.md)

Личный Telegram-бот, который:

- **Telegram-канал:** придумывает 5 идей, пишет пост по выбранной, правит его по твоим словам, добавляет фото и **выпускает в канал только после твоей кнопки «🚀 Выпустить в ТГК» и подтверждения «✅ Да»**.
- **TikTok:** придумывает 5 идей, пишет сценарий (хук, кадры, что говорить, призыв, советы по съёмке). Ты снимаешь и присылаешь видео, бот монтирует и пишет описание с хэштегами. Выкладываешь ты.

Что делает автомонтаж:
1. Вырезает паузы и запинки между фразами.
2. Чистит звук: убирает гул, подавляет шум, выравнивает громкость (спасает слабый микрофон).
3. Делает вертикальное видео 1080×1920 и слегка добавляет сочности картинке.
4. Распознаёт речь и вшивает крупные субтитры по 2–3 слова, как в рилсах.

Пользоваться ботом можешь только ты: сообщения от других людей он игнорирует.

## Установка (Windows)

**1. ffmpeg** (программа для монтажа). В PowerShell:

```
winget install ffmpeg
```

Закрой и снова открой терминал, проверь: `ffmpeg -version`.

**2. Бот в Telegram.** Напиши @BotFather → `/newbot` → получишь токен.
Свой id узнай у @userinfobot.

**3. Канал.** Создай канал, сделай ему публичную ссылку (@имя). Добавь своего бота в администраторы канала с правом «Публикация сообщений».

**4. Нейросеть (по желанию).** Выбери один вариант или ни одного:

| Вариант | Цена | Где взять ключ | Замечания |
|---|---|---|---|
| **Без нейросети** | бесплатно | не нужен | Идеи и тексты берёшь у Claude в чате, присылаешь боту, он публикует по кнопке. Монтаж работает |
| **GigaChat** | бесплатный лимит для физлиц | developers.sber.ru → GigaChat API → «Ключ авторизации» | Работает из России без VPN. Тексты чуть проще, чем у Claude |
| **OpenRouter** | бесплатные модели с пометкой `:free` | openrouter.ai/keys | Лимит бесплатных запросов в день. Может понадобиться VPN |
| **Claude API** | платно, центы за запрос | console.anthropic.com | Зарубежная карта и VPN. Лучшее качество |

Актуальные бесплатные лимиты проверь на сайте сервиса: они меняются.

**5. Библиотеки.** В папке бота:

```
pip install -r requirements.txt
```

**6. Настройки.** Скопируй `.env.example` в `.env`, заполни 3 обязательные строки и ключ выбранной нейросети. Если ключа нет, бот запустится в режиме без нейросети.

**7. Запуск:** `python bot.py` или двойной щелчок по `run.bat`. В Telegram напиши боту `/start`.

## Как пользоваться

| Кнопка | Что происходит |
|---|---|
| 💡 Идеи для ТГК | 5 идей → «✍️ Пост N» → черновик с кнопками: Выпустить, Правки, Переписать, Добавить фото, Удалить |
| 🎬 Идеи для TikTok | 5 идей → «🎬 Сценарий N» → снимаешь → «🎥 Снял, монтируй» → присылаешь видео |
| ✍️ Пост на свою тему | Пишешь тему своими словами → черновик |
| 📋 Готовый пост в канал | Присылаешь готовый текст (можно фото с подписью) → черновик с кнопкой «Выпустить» |
| 🎞 Смонтировать видео | Любое видео без идеи: просто пришли его |

Можно и без кнопок: просто пришли боту текст или фото с подписью. Без нейросети он сразу сделает черновик, с нейросетью спросит, это готовый пост или тема для нового.

Видео присылай как **обычное видео, не файлом**: Telegram сожмёт его до лимита ботов в 20 МБ. Готовый ролик бот присылает файлом, чтобы не терялось качество.

## Настройка под себя

- **profile.md** — кто ты, о чём канал, какой тон. Бот читает его перед каждым запросом, правки работают без перезапуска. Чем точнее профиль, тем лучше идеи.
- **.env** — нейросеть и её ключ, субтитры вкл/выкл, нарезка пауз вкл/выкл.

## Что важно знать

- **Бот работает, пока включён компьютер.** Чтобы он работал 24/7, его можно перенести на VPS (монтаж там будет медленнее, если сервер слабый).
- **Одна копия на один токен.** Если запустить бота с тем же `BOT_TOKEN` на двух компьютерах сразу, Telegram выдаст ошибку `Conflict`. Перед запуском на ноутбуке выключи бота на ПК.
- **Первый ролик монтируется дольше:** скачивается модель распознавания речи (~500 МБ). Дальше минутный ролик монтируется примерно 1–3 минуты в зависимости от компьютера. Если долго, поставь `WHISPER_MODEL=base`.
- **Если речь в паузах режется,** значит у тебя тихий микрофон или шумная комната. Порог тишины -35 дБ задаётся в `video.py`, в функции `speech_intervals` (параметр `noise_db`).
- **Горизонтальное видео** обрезается по центру до вертикального. Снимай сразу вертикально.
- **Нейросеть можно сменить в любой момент:** поменяй ключ в `.env` и перезапусти бота. В приветствии `/start` бот пишет, какая нейросеть сейчас работает.

## Файлы

| Файл | Что внутри |
|---|---|
| bot.py | кнопки, меню, публикация в канал, приём видео |
| llm.py | запросы к нейросети (Claude, GigaChat, OpenRouter): идеи, посты, сценарии, описания |
| video.py | автомонтаж через ffmpeg и субтитры через faster-whisper |
| storage.py | база SQLite с идеями и черновиками (content.db) |
| config.py | чтение настроек из .env |
| profile.md | твой профиль автора для нейросети |
